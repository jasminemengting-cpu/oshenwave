其他收集方式（書籤小工具）
  1. 電腦版 Chrome / Edge：把這個按鈕拖到書籤列 👉 🌊 收集留言
  2. 到 threads.com 打開你的抽獎貼文（建議先登入，才看得到全部留言）
  3. 點書籤列上的「🌊 收集留言」，它會自動往下捲動收集，完成後按「複製」
  4. 回到這裡，貼到下面的步驟 2
書籤列沒出現 / 想用主控台執行

Mac 按 ⌘ + Shift + B、Windows 按 Ctrl + Shift + B 可以顯示書籤列。
也可以在 Threads 貼文頁按 F12 打開「Console / 主控台」，貼上程式碼後按 Enter。

也可以貼上 Python 版產生的 comments.csv，或是一行一個帳號的名單。
